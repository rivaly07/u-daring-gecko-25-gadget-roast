A tiny local program that writes one original daily-gadget roast to `entry.txt`.

Run with Node 22:

```sh
node --experimental-strip-types main.ts
```

By default the program writes to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory.
